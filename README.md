# SkillAcademy

Proyecto organizado por partes para separar frontend, backend, documentación, entregables y widgets.

## Estructura

```text
backend-fastify/      API con Fastify y endpoints ya implementados
frontend-angular/    Aplicación Angular
documentacion/       Documentos, evidencias y scripts de documentación
entregables/         Archivos zip o entregas comprimidas
widgets/             Código de widgets externos, como Flutter
```

## Ejecutar Backend

```bash
cd backend-fastify
npm.cmd start
```

El backend corre en:

```text
http://localhost:3000
```

## Ejecutar Frontend Angular

```bash
cd frontend-angular
npm.cmd start
```

Angular corre en:

```text
http://localhost:4200
```

## Rutas Principales

```text
http://localhost:4200/dashboard
http://localhost:4200/smart-tv
http://localhost:4200/wearable
```
